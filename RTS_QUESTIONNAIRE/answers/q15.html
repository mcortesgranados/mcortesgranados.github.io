Technical detail

  • 🧠 Generative AI delivery — RAG pipelines (chunking strategies, embeddings, vector search with FAISS/pgvector-style stores), prompt design and versioning, context-window and cost management, response guardrails, and evaluation with metrics such as EM/F1/ROUGE plus human review.
  • 🛠️ Model fine-tuning — parameter-efficient training (4-bit quantized QLoRA adapters on Llama-3-class models) over domain datasets, with loss tracking and adapters served behind a FastAPI inference API (/ask style endpoints).
  • 🤝 Provider integration — OpenAI APIs, Gemini, Claude and local/open-source models behind a common abstraction so a project can switch provider or fall back without rewriting business logic.
  • 🤖 Agentic AI — durable tool-calling workflows where agents plan, call APIs/databases, validate outputs and retry safely; idempotent side effects, structured tool schemas, human-in-the-loop approval gates, tracing and cost/rate-limit control.
  • 🔌 MCP (Model Context Protocol) — the client/server model for exposing tools, resources and prompts to LLM hosts; designing MCP servers that wrap internal systems with least-privilege access, typed schemas and audit logging, so assistants reach enterprise data in a governed way.

🔐 Governance is part of the delivery: PII handling and anonymisation, least-privilege credentials, prompt-injection awareness, and observability over token usage.
