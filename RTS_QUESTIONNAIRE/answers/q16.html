Have you used AI-assisted/vibe-coding tools such as Cursor, Claude, GitHub Copilot, or similar tools?

AI ToolingProductivity

✅ Yes — I have used AI-assisted development tooling daily since approximately 2022, with ChatGPT, GitHub Copilot, Cursor, Claude, Gemini and OpenAI APIs.

Technical detail

  • ⌨️ In-editor assistance — Cursor and GitHub Copilot for scaffolding, boilerplate generation, refactoring, docstring/comment generation, translating code between stacks (Java ↔ C# ↔ TypeScript), and explaining unfamiliar legacy code quickly.
  • 🧪 Testing and quality — generating unit/integration test skeletons (xUnit/NUnit, JUnit, pytest, Jest, Jasmine), edge-case discovery, and using AI to review diffs for security and consistency before human approval.
  • 📚 Design and documentation — using conversational models to challenge architecture options, draft ADRs, OpenAPI descriptions, runbooks and migration plans, always validated against the actual codebase and framework docs.
  • 🧭 Discipline I apply — AI output is treated as a draft, never as authority: I review for correctness, security, licence/attribution and performance, keep secrets out of prompts, and ensure generated code matches team standards and is covered by tests. This keeps velocity high without lowering the engineering bar.

🚀 Net effect on delivery: faster onboarding into new codebases, quicker PoC cycles, and more time focused on architecture, domain modelling and production hardening — the parts where human judgement matters most.

🧾 CV evidence: 2025 CV: 'Actively using AI-assisted engineering workflows with ChatGPT, GitHub Copilot, Cursor, OpenAI APIs, Gemini, and Claude...' and the AI-assisted delivery trajectory since ~2022.
