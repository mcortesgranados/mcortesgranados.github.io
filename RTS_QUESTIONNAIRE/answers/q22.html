Have you worked on responsive UIs for different viewport sizes such as mobile, tablet, laptop, and desktop?

ResponsiveFrontendUX

✅ Yes — responsive delivery across mobile, tablet, laptop and large desktop is a baseline requirement in all my UI work.

Technical detail

  • 📱 Mobile (≈320-480px) — single-column layouts, touch targets ≥44px, bottom-sheet/navigation patterns, collapsible sections, virtualised lists and simplified tables that transform into card views.
  • 📲 Tablet (≈768-1024px) — two-column grids, split panes, adaptive side navigation and gesture-friendly spacing for hybrid input.
  • 💻 Laptop (≈1280-1440px) — multi-column dashboards, sidebars, dense data grids with sticky headers and expanded detail panels.
  • 🖥️ Desktop/large (≥1600px) — full-width analytics layouts, multi-panel workbenches and max-width content containers so text lines stay readable.

🧰 Techniques and tooling: mobile-first media queries and a shared breakpoint map, CSS Grid/Flexbox with fluid units, clamp() typography, container queries for component-level adaptation, Angular CDK Layout BreakpointObserver for behaviour changes (not just styling), responsive images with srcset, and Angular Material/CDK responsive components.

🧪 I validate with real viewports in devtools, check orientation changes and zoom, verify keyboard/touch interaction, and run accessibility checks (contrast, focus order, reduced motion) before release — responsive is treated as a functional requirement, not a cosmetic pass.

🧾 CV evidence: 2025 CV front-end expertise: 'Advanced expertise optimizing performance and accessibility in responsive UIs' and 'Strong ability building UIs that adapt across devices'; Angular/React delivery in current and previous roles.
