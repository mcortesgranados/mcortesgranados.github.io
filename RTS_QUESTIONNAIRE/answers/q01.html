Which versions of .NET / .NET Core have you worked with?

.NETC#Backend

✅ Yes — I have delivered production solutions across the full .NET evolution, from the classic Framework line into modern cross-platform .NET.

Technical detail

  • 🧩 .NET Framework 4.x — ASP.NET MVC, Web API 2, WCF services, Windows Forms/WPF desktop clients and T-SQL data layers on SQL Server.
  • 🐧 .NET Core 3.1 — first cross-platform wave: ASP.NET Core Web API, DI container built into the host, Kestrel, Docker images on Linux.
  • 🚀 Modern .NET (5, 6, 7, 8) — minimal APIs, top-level statements, record types, IHostedService background workers, rate limiting middleware, native AOT awareness and OpenTelemetry instrumentation.

💡 My working style with the platform: layered solutions (API / Application / Domain / Infrastructure), constructor Dependency Injection, async/await end-to-end, IHttpClientFactory for outbound calls, and EF Core or micro-ORM data access. 🧪 Testing is part of the delivery: NUnit, MSTest, xUnit-style fixtures and integration tests through WebApplicationFactory. 📦 Packaging and release through dotnet build/test/publish in CI pipelines with Docker images.

🆕 Most recently I combined a .NET backend with an Angular front end in a Document Management System (controllers, services, Swagger, JWT and SQL persistence working together), which keeps my .NET knowledge current and hands-on.

🧾 CV evidence: CV .NET Technologies line: C#, ASP.NET MVC and ASP.NET Core, Entity Framework, Web API, .NET Core, Dependency Injection, NUnit, MSTest, MVVM, Xamarin, WPF, WCF, REST in .NET; Globant role as Senior .NET Developer; 2025 DMS Angular + .NET assessment.
