Technical detail

  • ⚛️ React 19 — function components and hooks, context and reducer state, custom hooks, code splitting with React.lazy/Suspense, React Router, form libraries, and testing with Jest/React Testing Library. Used in senior front-end roles and as a consultant for public-sector platforms.
  • ▲ Next.js — file-based routing, server-side rendering/static generation, API routes, and image optimisation for SEO-sensitive products.

🎯 I choose the framework based on team skills, SEO/rendering needs, ecosystem fit and long-term maintenance cost — and I can migrate incrementally (for example Angular module → standalone, or page-by-page React adoption inside a legacy app).
