Have you worked with Angular concepts such as lazy-loaded modules, route guards, interceptors, RxJS, state management, reusable components, custom directives/pipes, and reactive forms?

AngularRxJSFrontend

✅ Yes — all of these are part of my everyday Angular practice, not occasional exposure.

Technical detail

  • ⏳ Lazy loading — route-level loadChildren/loadComponent for feature areas, preloading strategies for critical modules, and bundle-budget enforcement so the initial payload stays small.
  • 🛡️ Route guards — CanActivate/functional guards for authentication and role checks, CanDeactivate for unsaved-changes protection, resolvers for pre-fetching data, and CanLoad-style protection of lazy chunks.
  • 🔄 Interceptors — JWT injection, refresh-token retry, correlation headers, global error handling/notification, loading indicators and response caching, all composed in a predictable order.
  • 🌊 RxJS — observables and subjects, higher-order operators (switchMap, concatMap, mergeMap, exhaustMap), combineLatest/forkJoin, debounceTime/distinctUntilChanged for type-ahead, catchError/retry resilience, shareReplay for caching, and disciplined subscription lifecycle with takeUntilDestroyed or the async pipe.
  • 🗃️ State management — NgRx-style stores (actions, reducers, selectors, effects) for complex flows, and signal-based local stores for lighter features; server state kept separate from UI state.
  • 🧩 Reusable components, directives and pipes — presentational components with typed inputs/outputs, content projection, custom structural/attribute directives, pure pipes for formatting, and a shared library published for reuse across apps.
  • 📝 Reactive forms — typed form groups, dynamic form generation, custom and cross-field validators, async validators, dirty/touched UX and mapping to DTOs.
🧾 CV evidence: 2025 CV: 'Advanced Angular 17/18 delivery with TypeScript, Router, HttpClient, RxJS, standalone and modular components, Jasmine/Karma testing'; DMS Angular + .NET assessment referencing RxJS observables and Angular CLI modules.
