Role summary

We are looking for a Full Stack Developer based in Bogotá to design, develop, and enhance enterprise applications using modern .NET and Angular technologies.

This role requires strong hands-on expertise across both backend and frontend development, with particular emphasis on .NET 8+, Angular 13+, C#, TypeScript, REST APIs, databases, and modern software architecture.

You will build responsive user interfaces, backend services, integrations, and scalable application components while collaborating closely with Product, QA, and Engineering teams throughout the software development lifecycle.

Responsibilities

  • Develop and maintain enterprise applications using .NET 8+ and Angular 13+.
  • Build responsive web interfaces using Angular, TypeScript, JavaScript, CSS3, and SCSS.
  • Develop Angular applications from initial architecture and project setup through production implementation.
  • Build reusable Angular components, modules, services, directives, and pipes.
  • Implement lazy loading, route guards, interceptors, RxJS, state management, and reactive forms.
  • Design and implement RESTful APIs and third-party integrations.
  • Develop multi-layered .NET applications with clear separation between API/presentation, business/application, and data-access responsibilities.
  • Apply software architecture principles including separation of concerns, loose coupling, and high cohesion.
  • Implement dependency injection and appropriate data-access/ORM patterns.
  • Develop secure authentication and authorization functionality.
  • Design, query, and optimize relational and NoSQL databases.
  • Write unit tests and participate in peer code reviews.
  • Troubleshoot and resolve application, database, API, and integration defects.
  • Diagnose issues across development, QA, and production environments.
  • Improve application performance, scalability, maintainability, and reliability.
  • Work with Docker, Kubernetes, and microservices-based environments.
  • Use Git and Azure DevOps as part of the development lifecycle.
  • Use AI-assisted development tools while independently reviewing, validating, and testing generated code.
  • Collaborate with Product, QA, Engineering, and US-based stakeholders throughout the SDLC.
  • Support production deployments and incident resolution when required.

Requirements – Must-haves

  • Currently living in Bogotá, Colombia, and able to work from Bogotá.
  • Availability to attend the Bogotá office when requested.
  • Legal authorization to work in Colombia.
  • English proficiency at B2+ level or higher, with the ability to participate effectively in technical discussions with US-based teams.
  • Spanish C1.
  • Bachelor’s degree in Computer Science, Information Technology, or a related field.
  • 4+ years of professional full-stack software development experience.
  • Current hands-on professional experience with .NET 8 or later.
  • Current hands-on professional experience with Angular 13 or later.
  • Experience building Angular applications from scratch, including initial architecture and project setup.
  • Experience working on Angular applications containing at least five modules.
  • Hands-on Angular experience with:
    • Lazy-loaded modules
    • Route guards
    • Interceptors
    • RxJS
    • State management
    • Reusable components
    • Custom directives and pipes
    • Reactive forms
  • Strong programming skills in C#, TypeScript, and JavaScript.
  • Strong experience with CSS3 and SCSS for responsive UI development.
  • Experience with EF Core, Dapper, or another ORM/data-access framework.
  • Experience with dependency injection and IoC, including built-in .NET DI or comparable frameworks.
  • Experience implementing authentication and authorization using OAuth 2.0, OpenID Connect, or comparable technologies.
  • At least 2 years of experience with relational databases, such as SQL Server or PostgreSQL.
  • At least 1 year of experience with NoSQL databases, such as MongoDB.
  • Experience developing multi-layered .NET applications with clear API/presentation, business/application, and data-access layers.
  • Strong experience building and consuming RESTful APIs.
  • Experience with Git and Azure DevOps.
  • Experience with Docker, Kubernetes, and microservices architecture.
  • Hands-on experience using AI-assisted development tools such as GitHub Copilot, Cursor, Claude, or similar technologies.
  • Strong analytical, troubleshooting, communication, and collaboration skills.
